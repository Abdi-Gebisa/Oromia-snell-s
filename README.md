# OromiaSTEM — Natural Lab Edition

A calm, accessible, student-friendly visual refresh of OromiaSTEM, retaining the existing subject navigation and simulation modules.

## Design direction
- Natural forest-green and warm-white palette
- Clear typography, spacious cards, restrained shadows
- Less visual clutter and no excessive neon effects
- Responsive layout for phones, tablets and desktop
- Existing Physics, Chemistry, Mathematics and Biology modules retained

## Publish
1. Extract this ZIP.
2. Upload the contents to the root of your GitHub Pages repository, replacing the previous version.
3. Commit the changes and wait for GitHub Pages to deploy.

This package has not been published to the live GitHub Pages site. Test the simulations in a browser after deployment.
